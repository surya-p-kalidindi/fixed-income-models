# fixed-income-models

Bond analytics implemented from scratch in Python — no financial libraries
perform the mathematics.

**Implemented**
- Bond price (semiannual or arbitrary frequency)
- Yield to maturity (bisection solver)
- Macaulay duration

**In progress**
- Modified duration, DV01, convexity
- Assertion suite against independently calculated benchmarks

**Roadmap**
- Mortgage pool cash flows (CPR/SMM, CDR/MDR, losses)
- Rate shocks, effective duration and convexity, Z-spread
- Option-adjusted spread
